Fitur Unggulan Presensi Terbaru

1. Sinkronisasi Otomatis Harian

Memungkinkan data siswa tersinkronisasi setiap hari agar dapat digunakan dengan lancar dalam mode online maupun offline.

2. Presensi Scan QR Code

Mempermudah guru melakukan absensi dengan memindai kartu QR Code siswa secara praktis.

3. Presensi Manual

Memungkinkan guru mencatat kehadiran murid secara langsung dengan memilih status (Hadir, Sakit, Izin, atau Alpa).

4. Antrean Offline

Data presensi saat offline tersimpan otomatis dan akan dikirimkan kembali seketika perangkat terhubung ke internet.

5. Rekapitulasi Fleksibel

Memiliki fitur penggantian bulan pada rekapitulasi presensi untuk memudahkan pengecekan data bulanan.
